# 코드 반주 (Chord Accompanist)

화면에 코드 진행을 보여주고, 사용자가 코드 버튼을 짚고 있는 동안 그 코드로 반주(베이스 + 기타 스트럼)를 들려주는 모바일 앱입니다.

## 기능

- **연습 모드:** 코드 진행(팝 기본, 캐논, 블루스 등)을 고르면 지금 칠 코드와 다음 코드를 보여줍니다. 맞는 코드를 한 마디 동안 짚고 있으면 다음 코드로 넘어갑니다.
- **반주:** 버튼을 누르고 있는 동안 반복 재생하고, 떼면 멈춥니다. 여러 개를 누르면 마지막에 누른 코드가 재생됩니다.
- **전체 코드:** 12개 근음 × 메이저/마이너/7 코드를 자유롭게 연주할 수 있습니다.
- 템포는 90 BPM 고정입니다.

## 실행

```bash
npm install
npx expo start
```

휴대폰에 **Expo Go** 앱을 설치하고, 터미널에 뜨는 QR 코드를 찍으면 바로 실행됩니다.

## 반주 소리 다시 만들기

반주는 `scripts/generate-chords.mjs`가 합성한 WAV 파일(`assets/chords/`)입니다. 패턴, 템포, 코드 종류를 바꾸려면 스크립트를 고친 뒤 다시 실행하세요.

```bash
npm run generate:chords
```

## 구조

| 경로 | 내용 |
|------|------|
| `App.tsx` | 화면 |
| `src/music.ts` | 코드 이름, 코드 진행 목록 |
| `src/useChordPlayer.ts` | 누르는 동안 반복 재생하는 플레이어 |
| `src/chordSounds.ts` | 코드 → 소리 파일 목록 (자동 생성) |
| `scripts/generate-chords.mjs` | 반주 합성 스크립트 |
